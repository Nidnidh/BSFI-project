# Project 1 — BFSI Credit Risk Analytics


## Run step by step
1. Install MySQL 8+ and MySQL Workbench.
2. Create a schema by running `sql/01_schema.sql`.
3. Use Workbench's Table Data Import Wizard to import `data/borrowers.csv`, `data/loans.csv`, and `data/repayments.csv` in that order.
4. Run `sql/02_load_data_instructions.sql` to validate row counts.
5. Run `sql/03_business_analysis_queries.sql` one query block at a time.
6. Open Power BI Desktop; Get Data → Text/CSV and import the same three CSVs.
7. Create relationships as described in `powerbi/POWER_BI_BUILD_GUIDE.md`.
8. Add the measures and build the three report pages.
9. Reconcile at least five dashboard KPIs against SQL results.
10. Complete recommendations and limitations in the project report.

See `documentation/PROJECT_BRIEF.md` for the business case.
